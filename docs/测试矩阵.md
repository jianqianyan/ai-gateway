# AI Gateway 测试矩阵

> 维护规则见 [Agent.md](../Agent.md)。新增功能必须同步更新本表，并在 `scripts/regression-api.mjs` / `scripts/regression-ui.mjs` 中补充断言。

## 1. 测试入口

| 命令 | 内容 |
|---|---|
| `pnpm test` | 后端单元测试 |
| `pnpm test:api` | API 功能回归（153 项断言） |
| `pnpm test:ui` | 浏览器页面回归（23 项断言） |
| `pnpm test:regression` | 镜像检查 + 健康检查 + 单元 + API + 页面全量回归 |
| `pnpm smoke` | 核心链路验收（72 项断言） |
| `pnpm test:ui:smoke` | 页面渲染 + 管理员/只读账号冒烟 |

## 3. 回归数据隔离

| 前缀 | 用途 | 清理 |
|---|---|---|
| `reg-` | API 回归临时资源 | 脚本 `finally` 清理 |
| `ui-` | 页面回归临时资源 | 脚本 `finally` 清理 |
| `smoke-` / `Smoke ` | 核心验收临时资源 | 验收脚本启动时清理 |
| `demo-` | 演示环境资源 | 保留，不作为测试临时数据 |
