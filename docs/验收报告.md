## 5. 验证命令

```bash
# 启动全栈（含 Mock）
docker compose --profile test up -d --build

# 健康检查
curl http://localhost:8080/health

# 后端单元测试
pnpm test

# API 功能回归
pnpm test:api

# 页面回归
pnpm test:ui

# 一键全量回归（推荐）
$env:BASE_URL='http://localhost:8080'
$env:MOCK_ORIGIN='http://mock-upstream:4010'
pnpm test:regression

# 构建
pnpm -r build
```

## 6. 备注

- 首次启动会自动执行 Prisma 迁移并创建管理员/只读账号、内置敏感规则和默认策略。
- 演示数据由 `node scripts/seed-demo.mjs` 生成；该脚本适用于空数据库。
- 所有 Docker 镜像统一使用 `docker.m.daocloud.io/` 前缀，`pnpm test:regression` 会静态检查。
- 测试维护规范见 [Agent.md](../Agent.md)，功能覆盖矩阵见 [测试矩阵.md](./测试矩阵.md)。
- 生产部署前请修改默认密码、`JWT_SECRET`、`ENCRYPTION_KEY`，并将 `ALLOW_PRIVATE_UPSTREAMS` 设为 `false`。
